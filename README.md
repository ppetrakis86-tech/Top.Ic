# mini-bpe-tokenizer

Ένας μικρός tokenizer **Byte Pair Encoding (BPE)** σε καθαρή Python, χωρίς εξαρτήσεις. Φτιαγμένος για να καταλάβω πώς δουλεύουν οι tokenizers των γλωσσικών μοντέλων.

## Πώς δουλεύει

1. **Pre-tokenization**: κάθε κενό γίνεται `▁` και κολλάει μπροστά στη λέξη που ακολουθεί. Το κείμενο χωρίζεται σε λέξεις, αριθμούς και σύμβολα. Αλλαγές γραμμής και tabs μένουν ως έχουν.
   `"bananas, 42!\n"` → `["bananas", ",", "▁42", "!", "\n"]`
2. **Training**: κάθε κομμάτι σπάει σε χαρακτήρες. Σε κάθε βήμα, το πιο συχνό ζευγάρι γειτονικών symbols ενώνεται σε ένα νέο token (π.χ. `a` + `n` → `an`).
3. **Encode**: ένα καινούργιο κείμενο σπάει σε χαρακτήρες και τα merges εφαρμόζονται με τη σειρά που εκπαιδεύτηκαν. Το `decode` ενώνει τα tokens και γυρνάει το `▁` σε κενό, οπότε `decode(encode(x)) == x` **ακριβώς**, χωρίς να χάνεται τίποτα. Όσοι χαρακτήρες δεν εμφανίστηκαν ποτέ στο training (π.χ. emoji) σπάνε σε UTF-8 bytes (`<f0>`, `<9f>` …), οπότε ποτέ δεν υπάρχει "άγνωστο" σύμβολο.

Το training είναι **incremental**. Κάθε τρέξιμο φορτώνει τα προηγούμενα merges και προσθέτει καινούργια, χωρίς να ξεκινάει από το μηδέν.

Η εκπαίδευση δεν ξαναμετράει όλα τα ζευγάρια σε κάθε βήμα. Κρατάει πόσες φορές εμφανίζεται κάθε ζευγάρι και σε ποιες λέξεις, και ενημερώνει μόνο τις λέξεις που αλλάζουν. Έτσι 14.000 merges πάνω σε 2 εκατομμύρια χαρακτήρες παίρνουν λίγα δευτερόλεπτα.

Κάθε token έχει ένα σταθερό **id**: 0–255 για τα bytes, και μετά οι χαρακτήρες και τα merges με τη σειρά που προστέθηκαν. Τα ids δεν αλλάζουν όταν συνεχίζεις το training.

## Χρήση

Χρειάζεται Python 3.8+, χωρίς εξαρτήσεις.

```bash
python3 tokenizer.py --text corpus.txt                 # εκπαιδεύει 14000 νέα merges
python3 tokenizer.py --text corpus.txt --merges 500    # λιγότερα merges
python3 tokenizer.py --merges 0 --test "καλημέρα"      # μόνο encode, χωρίς training
```

| Παράμετρος | Default | |
|---|---|---|
| `--text` | `text.txt` | Κείμενο εκπαίδευσης (αν δεν υπάρχει, δημιουργείται με ένα κείμενο παράδειγμα) |
| `--model` | `merges.json` | Αρχείο μοντέλου που φορτώνεται και ξανααποθηκεύεται |
| `--merges` | `14000` | Πόσα νέα merges να εκπαιδεύσει |
| `--test` | `"I like green bananas and apples"` | Πρόταση για encode/decode στο τέλος |
| `--verbose` | | Τύπωσε κάθε merge (αλλιώς τα 10 πρώτα και ένα κάθε 1000) |

Παράδειγμα εξόδου:

```
🎯 Final Tokens:
['kalispera', ',', '▁ti', '▁kaneis', '?', '▁θέλω', '▁να', '▁κάνω', '▁allagi', '▁', '😀']
🔢 IDs: [8410, 270, 994, 2355, 289, 1397, 694, 1486, 6017, 478, 615]
🔁 Decode: 'kalispera, ti kaneis? θέλω να κάνω allagi 😀'
```

Από κώδικα:

```python
from tokenizer import Tokenizer

tok = Tokenizer.load("merges.json")
ids = tok.encode("I like green bananas")
print(tok.tokenize("I like green bananas"))   # tokens ως strings
print(tok.decode(ids))
```

## Περιορισμοί

- Ένα πραγματικό `▁` (U+2581) μέσα στο κείμενο γυρνάει στο decode ως κενό.
- Τα μοντέλα του παλιού σχήματος με `</w>` δεν φορτώνονται. Σβήσε το `merges.json` και εκπαίδευσε από την αρχή.

## Τεστ

```bash
python3 -m unittest -v
```

Ελέγχουν, μεταξύ άλλων, ότι η γρήγορη εκπαίδευση διαλέγει σε κάθε βήμα το ίδιο ζευγάρι με μια απλή, αργή υλοποίηση, και ότι `decode(encode(x)) == x` ακριβώς, μαζί με κενά, αλλαγές γραμμής και emoji.

| Αρχείο | Περιεχόμενο |
